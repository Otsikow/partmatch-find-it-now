# Standard Workflow

1. **Analyze**: Understand the requirements and existing codebase.
2. **Plan**: Create a step-by-step plan for changes.
3. **Implement**: Write code, strictly following user rules.
4. **Verify**: Run lint, build, and tests to ensure correctness.
5. **Review**: Check against "professional" standards (no console.logs, proper types).
